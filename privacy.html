プライバシーポリシー

最終更新日: 2026年10月11日

1. 概要

「家計台帳」(以下「本アプリ」)は、開発者本人および本人が許可した家族が、自宅のコンピュータ上で使う個人用の家計簿アプリです。 本アプリは、利用者のデータを開発者のサーバーへ送信・保存することはありません。

2. 取得するGoogleユーザーデータ

本アプリは、Gmail APIの読み取り専用スコープ(https://www.googleapis.com/auth/gmail.readonly)を利用し、 利用者自身が「領収書」というラベルを付けたメールの、件名・送信元・本文を取得します。 それ以外のメールは処理の対象にしません。メールの送信・変更・削除は行いません。

3. 利用目的

取得したメールの内容は、店舗名・購入日・金額・品目などの支出情報を読み取り、家計簿として記録する目的にのみ利用します。 広告、プロファイリング、販売、その他の目的には利用しません。

4. 外部サービスへの送信

支出情報を読み取るため、メール本文のテキスト(およびレシート画像)を、GoogleのGemini APIに送信して構造化処理を行います。 この送信は、上記の目的を実現するために必要な範囲に限られ、Gemini APIの利用規約およびプライバシーに関する条件に従って処理されます。 上記以外の第三者に、データを提供・販売・共有することはありません。

5. 保存と管理

読み取った支出情報、メール本文、認証トークンは、利用者のコンピュータ内のファイル(SQLiteデータベースおよびトークンファイル)にのみ保存されます。 クラウドや開発者の管理するサーバーには保存されません。

6. 人による閲覧

メールの内容は、利用者本人(および本人が許可した家族)が、本アプリの確認画面で自分たちのデータを確認する場合を除き、人が閲覧することはありません。

7. データの削除・アクセス権の取り消し

Googleアカウントの「サードパーティによるアクセス」の設定画面から、本アプリのアクセス権をいつでも取り消せます。 また、コンピュータ内のデータベースファイルとトークンファイルを削除することで、保存されているデータをすべて削除できます。

8. Google API サービスのユーザーデータに関するポリシー

本アプリによる、Google APIから受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー (限定的な使用の要件を含む)に準拠します。

9. 改定

本ポリシーは、必要に応じて改定することがあります。改定後は、このページに掲載します。

English summary

"Kakei Daicho" is a personal household-ledger app run on the developer's own computer. It uses the Gmail read-only scope to read only emails the user has labeled "領収書" (receipts), and sends the email text to Google's Gemini API solely to extract expense data (store, date, amount, items). Data is stored locally on the user's computer and is not sent to or stored on any server operated by the developer. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account permissions page.
